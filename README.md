# QCA Wiki

This repository contains the Cornell Quantum Computing Association wiki, built with [Astro](https://astro.build/) and [Starlight](https://starlight.astro.build/).

The site collects introductory quantum computing notes, gates and circuits references, algorithm pages, NISQ material, workshop resources, and archived course materials.

## Tech Stack

- Astro 6
- Starlight docs theme
- `starlight-katex` for LaTeX math rendering
- Markdown and MDX content under `src/content/docs`
- Static resources under `public/resources`

## Project Structure

```text
.
├── astro.config.mjs
├── package.json
├── public/
│   ├── bloch-sphere/
│   └── resources/
├── src/
│   ├── assets/
│   ├── content/
│   │   └── docs/
│   └── content.config.ts
└── tsconfig.json
```

Important content directories:

- `src/content/docs/fundamentals/` - introductory concepts
- `src/content/docs/qubits/` - qubit math, Bloch sphere, and hardware implementations
- `src/content/docs/gates/` - single-qubit and multi-qubit gates
- `src/content/docs/circuits/` - circuit notation and Qiskit examples
- `src/content/docs/algorithms/` - algorithms and protocols
- `src/content/docs/nisq/` - NISQ-era topics
- `src/content/docs/workshops/` - workshop landing pages
- `src/content/docs/archive/` - archived course material

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Build the static site:

```bash
npm run build
```

Preview a production build:

```bash
npm run preview
```

## Writing Pages

Docs pages live in `src/content/docs/` as `.md` or `.mdx` files. The route is based on the file path. For example:

```text
src/content/docs/circuits/qiskit-examples.md
```

builds to:

```text
/circuits/qiskit-examples/
```

Most pages use frontmatter like:

```md
---
title: Multi-Qubit Gates
---
```

Longer pages can also include `description` and `sidebar` metadata.

## Math

Use KaTeX-compatible LaTeX.

Inline math:

```md
$\ket{\psi} = \alpha\ket{0} + \beta\ket{1}$
```

Display math:

```md
$$
\ket{GHZ} = \frac{\ket{000} + \ket{111}}{\sqrt{2}}
$$
```

## Static Resources

Put PDFs, notebooks, slides, and other downloadable files in `public/resources/`. Files in `public/` are served from the site root.

For example:

```text
public/resources/fundamentals/week2/slides.pdf
```

is linked as:

```md
[Slides](/resources/fundamentals/week2/slides.pdf)
```

## Sidebar

The sidebar is configured in `astro.config.mjs`. Some sections are autogenerated from directories, while others are listed manually to control ordering.

When adding a new page, check whether its section is autogenerated or manually configured. If it is manual, add the new page path to the appropriate `items` list.

## Validation

Before committing content changes, run:

```bash
npm run build
```

This checks that content, routes, math, and static generation still compile.
