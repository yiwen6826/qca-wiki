Welcome to Cornell QCA's central hub for quantum education materials.

This wiki now serves two roles:

- A concept reference for quantum computing topics such as qubits, gates, hardware, and NISQ methods.
- A curriculum hub for QCA's lectures, workshops, and archived teaching materials.

## Start Here

- If you want a structured learning path, begin with [Quantum Computing Fundamentals](/fundamentals/).
- If you want a compact lecture on core algorithms, see [Quantum Algorithms](/algorithms/).
- If you want hands-on coding material, go to [Workshops](/workshops/).
- If you want prior semester material, browse the [Archive](/archive/).

## Current Learning Tracks

### Foundations

The foundations path is organized like a short textbook sequence. It starts with qubits as mathematical states, then moves through superposition, gates, Bloch-sphere intuition, and finally into algorithms and protocols.

Available pages currently cover:

- [Foundations overview](/fundamentals/)
- [Bits, Qubits, and Measurement](/fundamentals/week-1/)
- [Superposition and Quantum Gates](/fundamentals/week-2/)
- [Qubit Mathematics](/qubits/basic-info-theory/qubit-math/)
- [The Bloch Sphere](/qubits/basic-info-theory/bloch-sphere/)
